# 台股券商截圖離線記錄工具

依照需求提供 5 個功能：

1. 上傳每日券商截圖（如 `sample.png`）並擷取上方表格資料
2. 同步擷取上方總覽資訊（商品、現價、成本價、投資成本、帳面收入、損益、損益率）
3. 寫入本機離線資料庫（`SQLite`）
4. 依商品查詢曲線圖與明細表，支援起訖日期篩選
5. 自動計算每檔股票「日增減損益」

## 環境

- Python 3.10+
- 系統已安裝 `tesseract`（本專案用 CLI 呼叫 OCR，不依賴 `pytesseract`）

## 安裝

```bash
pip install -r requirements.txt
```

## 啟動

```bash
python3 app.py
```

開啟：`http://127.0.0.1:8765`

## 使用流程

1. 在「上傳與寫入」選擇日期與截圖
2. 點「解析截圖」取得 OCR 預覽
3. 若識別有誤，可直接在表格中手動修正
4. 可在總覽區補填「實際投資成本」與「剩餘資金」
5. 點「寫入 SQLite」存檔（同日同商品會更新）
6. 到「查詢與圖表」選擇商品與日期區間查看曲線與明細
7. 到「總投資」頁查看全商品每日加總趨勢
8. 到「區間清單」頁可查看指定日期區間內所有商品資料，並用商品勾選控制曲線與表格顯示

## 資料庫

- 檔案：`stock_journal.db`
- 表：
  - `daily_summary`
  - `daily_stock_records`

`daily_summary` 目前包含以下總覽欄位：

- `account`
- `total_profit_loss`
- `total_profit_rate`
- `total_investment_cost`
- `actual_investment_cost`
- `remaining_funds`
- `record_count`
- `raw_summary_text`

`daily_stock_records` 會維護欄位 `daily_profit_change`，公式為：

- `當日損益 - 前一個交易日損益`

## 注意

- OCR 會受截圖清晰度、字體與排版影響，系統設計為「先自動擷取，再人工修正後入庫」。
- 目前預設聚焦於截圖上方約 72% 區域以提高命中率。
